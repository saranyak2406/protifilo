# K. Saranya Sree — Full Stack Python Developer Portfolio

A personal developer portfolio website for **K. Saranya Sree**, built with **React.js + Vite** and **Tailwind CSS**.

Designed following an Apple-inspired minimal and modern design philosophy with a palette of deep obsidian blacks, crisp whites, and subtle emerald green accents.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
